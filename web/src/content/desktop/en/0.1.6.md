- **Start casting from the tray menu** (Windows): when nothing is cast, the tray menu lists the screens and windows under **Start casting**; choosing one casts it to the receiver you used last, without opening the window. If that receiver is not found or wants a password, the window opens and says why. While casting, the same entry is **Switch what is cast**.
- **About** opens the text of the licence (GPL-3.0) and the source code. The row used to open the list of releases, where there is no licence to read.
- **A key frame right after a dropped picture.** When the network cannot take a picture the sender drops it, and the pictures after it build on one the receiver never got. The next picture is now a full one (a key frame), so the picture mends at once instead of at the next regular key frame.
