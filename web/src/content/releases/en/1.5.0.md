- About → Diagnostics → Run network check helps when an iPhone, iPad or Mac can't find CastBay: it checks the receiver, the network and IP address, both AirPlay announcements (_airplay._tcp and _raop._tcp), the AirPlay port and the latest announcement failure, item by item as Pass, Problem or Can't verify, each with what to do next. It only reads: casting goes on undisturbed.
