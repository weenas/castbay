- Updates install from the TV: when a newer version is out, About offers **Download and install**. CastBay downloads it (from castbay.weenas.com, else GitHub), checks it is exactly the released file (its SHA-256), and opens Android's installer, where you confirm. The first time, the TV asks you to allow CastBay to install apps. Nothing is downloaded until you press the button, and the daily update check can still be turned off in Settings.
- The update check asks castbay.weenas.com first, so it works where GitHub is slow or blocked.
- The latest APK can now be downloaded from **castbay.weenas.com/apk**, short enough to type in a TV's browser. The user guide lists the ways to get CastBay onto a TV, and the changelog links each version's APK.
