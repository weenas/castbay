# Code of conduct

CastBay follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful and welcoming, assume good intent, keep discussions about the work, and don't harass anyone, in English, Chinese or any other language.

It applies to this repository's issues, pull requests and discussions, and to anyone representing the project elsewhere.

If someone's behaviour is unacceptable, use GitHub's "Report content" on the comment, or report it privately to the maintainers through [this private form](https://github.com/weenas/castbay/security/advisories/new) (mention that it is about conduct). Reports are handled confidentially; the maintainers may edit or remove contributions, or block people, who don't follow it.
