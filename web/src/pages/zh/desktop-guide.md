映湾桌面端使用自己的加密连接，不是 AirPlay 或 DLNA，所以延迟很低：家庭网络里约四分之一秒。

## 准备

- **Windows 10 或 11（64 位）**，带有 Microsoft Edge WebView2 运行库（Windows 11 和较新的 Windows 10 已自带）；或 **Ubuntu、Debian（64 位）**，使用 Wayland 和 PipeWire。
- 一台接收端：运行映湾的 Android 6.0 及以上设备（电视、电视盒子、车机或平板），在同一网络里（不要用访客网络），并在它的设置里开启**电脑投屏**。

## 安装

- **Windows 安装程序**（.msi，有中文和英文两个）：双击、下一步、完成，不需要管理员权限。它会添加开始菜单项和“设置 → 应用”里的卸载入口。运行新版安装程序会原地升级并保留配对记录。
- **Windows 免安装版**（.zip）：解压到任意位置，运行 **CastBay Desktop.exe**。不安装任何东西，删掉文件夹就卸载了。
- **Linux**（.deb）：`sudo apt install ./castbay-desktop_<版本>_amd64.deb`，然后在应用程序菜单里打开 **CastBay Desktop**。已在装有 GNOME 的 Ubuntu 26.04 上测试。

都可以在<a href="/zh/download">下载页</a>找到。

## 第一次投屏

1. 运行它。目前还没有代码签名，Windows SmartScreen 可能提示已保护你的电脑：点**更多信息**，再点**仍要运行**。
2. 如果 Windows 防火墙询问，请允许**专用网络**，否则找不到接收端。
3. 在列表里选接收端，选择**整个屏幕**或**指定窗口**（Linux 上在投屏开始时由系统询问要共享什么，见下文），点**开始投屏**。
4. 第一次连接时接收端会显示 6 位配对码，在窗口里输入即可，以后不用再输。

列表里每台接收端会写明它对新电脑的要求：**开放**（什么都不用）、需要在接收端的屏幕上确认，或需要配对码。这台电脑配对过的接收端只显示绿色的**已配对**。带锁的图标表示它还要密码，在窗口里输入。

## 投屏时

- 投屏页显示投到哪里和画面大小。**详细信息**（解码时间、帧率、丢帧、码率）默认收起。**停止投屏**结束投屏。
- **切换投屏内容**（Windows）：在投屏页或托盘菜单里换成另一个窗口或屏幕，不用结束投屏。被投的窗口如果关闭，画面会停在最后一帧，投屏等你选新的内容，窗口会自己回来询问。
- 默认**开始投屏后窗口会最小化**，关闭窗口时投屏继续在托盘里运行。
- 电脑锁屏时 Windows 不提供屏幕画面，所以画面会停住；窗口会提示，解锁后自动继续。投屏期间电脑不会自己休眠或息屏。
- 码率是上限：网络跟不上时会自动降低，平静二十秒后慢慢回升。

## 托盘菜单

点托盘图标打开窗口；右键打开菜单：

- **打开 CastBay Desktop** 和**设置**。
- **开始投屏**（没有投屏时，Windows）：列出可以选的屏幕和窗口，选一项就投到你上次用的接收端，不用打开窗口。如果那台接收端找不到或需要密码，窗口会打开并说明原因；第一次配对的配对码也要在窗口里输入。
- **切换投屏内容**（投屏时，Windows）：同样的列表，窗口打开或关闭时保持最新。
- **停止投屏**、**关于**和**退出**（退出会先结束正在进行的投屏）。

## 设置

点右上角的滑块图标。修改在下一次投屏时生效。

| 设置 | 作用 |
| --- | --- |
| 码率 | 2 到 20 Mbit/s 的滑动条（默认 8）。码率越高画面越清晰，也越占网络。 |
| 帧率 | 30 或 60 帧，是发送的上限。投屏跟着屏幕走：画面变得多快就发多快，最高到这个帧率；画面静止时降到每秒约 10 帧（投屏页的“详细信息”里会说明），一动就恢复。60 帧让游戏和拖动窗口更跟手，建议码率 8 Mbit/s 以上。 |
| 同时传声音 | 电脑播放的声音一起传过去（电脑上仍然播放）。在 Windows 上投某个窗口时，只传这个窗口的声音（浏览器也一样），不会带上别的程序正在放的音乐。投整个屏幕，以及在 Linux 上，传的是电脑播放的全部声音。 |
| 编码器 | 自动：依次尝试 AMD、NVIDIA、CPU（x264）。列表里只有这台电脑能用的。显卡用自己的视频编码单元，几乎不占 CPU。 |
| 开机自动启动 / 登录后自动启动 | 随电脑启动并在托盘待命。 |
| 启动时检查更新 | 程序启动时查一次新版本（窗口重新打开时也会再查，一小时最多一次）。 |
| 开始投屏后最小化窗口 | 默认开启。 |
| 语言 | 跟随系统、中文或英文（托盘菜单同步）。 |
| 发送匿名使用统计 | 默认关闭，见下文。 |
| 发送错误报告 | 默认关闭，见下文。 |
| 已配对的接收端 | 配对过的接收端和上次连接时间。**忘记**后下次投屏需要重新配对。 |
| 恢复默认设置 | 把上面的选项恢复默认（上次选的接收端和配对记录保留）。 |
| 关于 | 见下文。 |

## 关于、更新和问题反馈

**关于**（设置里，或托盘菜单）是一个窗口，显示版本和有没有新版本，有**更新内容**（官网更新日志）和**更新**按钮，另外还有：

- **检查更新**、**诊断信息**、**反馈问题**、**打开日志文件夹**、**开源许可证**（GPL-3.0 全文）和**源代码**（代码仓库）。
- **诊断信息**显示这台电脑的情况和日志的末尾。**上传日志**会先询问，再给出一个报告编号，反馈问题时附上即可。上传前会去掉网络地址、接收端的名字和你的用户文件夹，只有你点“上传”才会发送。

**更新**：主页上的更新提醒和“关于”里都有**更新**按钮。Windows 上它下载新的安装程序，用官网公布的 SHA-256 校验，安装后重新启动程序。Linux 上它在系统自己的对话框里要你的密码，然后安装新的 .deb。免安装版会打开发布页。提醒上的**忽略此版本**会让这个版本的提醒不再出现，出了更新的版本会重新提醒。

## Linux 说明

- **投什么**：窗口里没有屏幕和窗口的列表，点**开始投屏**时由系统询问要共享屏幕还是窗口。勾选“记住此选择”后不再询问；主界面的**重新选择**会让下一次投屏时重新询问。记住的选择失效时，映湾桌面端会在 15 秒后忘掉它，系统的对话框重新出现，再选一次即可。（保存在 `~/.local/share/castbay-desktop/screencast-token`，删除该文件效果相同。）
- **更换投屏内容**：投屏页的**更换投屏内容…**会再次打开系统的对话框，不用结束投屏。取消的话，仍投原来的内容。托盘菜单里的切换项在 Linux 上是灰的，因为只有系统的对话框能选。
- **托盘**：投屏中关闭窗口，投屏会继续在托盘里运行。GNOME 默认不显示托盘图标（安装 AppIndicator 扩展即可）；没有扩展时，再次从应用程序菜单打开 **CastBay Desktop**，正在运行的窗口会回到前台。
- **登录后自动启动**会写入 `~/.config/autostart/castbay-desktop.desktop`。
- **编码**：NVIDIA 显卡用 NVENC，其他用 CPU 的 x264（AMD、Intel 硬件编码暂未支持）。

<a id="linux-fullscreen"></a>

### 全屏播放视频时电视上的画面不动了

投**整个屏幕**时，如果在浏览器或播放器里把视频**全屏**播放，电视上的画面可能定格，而电脑自己的屏幕照常播放。这不是网络问题，也不是视频格式的问题。

- **原因**：全屏窗口盖住整个屏幕时，GNOME 会把这个窗口直接送到显示器（“直接扫描输出”），同时不再给录屏的程序提供新画面，直到别的东西重新绘制。这是 GNOME（mutter）自己的行为，在 Wayland 加 NVIDIA 显卡上会遇到，映湾桌面端无法从外部改变；相关报告见 [mutter 问题 3074](https://gitlab.gnome.org/GNOME/mutter/-/issues/3074)，KDE 也有类似的问题（[KDE bug 495287](https://bugs.kde.org/show_bug.cgi?id=495287)）。
- **办法**：改投**窗口**，不要投整个屏幕。系统询问共享什么时，选浏览器或播放器的窗口，这样全屏时画面也照常更新。如果系统没有询问，先点主界面的**重新选择**。已经在投屏幕的话，点投屏页的**更换投屏内容…**。

<a id="linux-sound"></a>

### 传的是整台电脑的声音，不是某个窗口的

**Windows** 上投某个窗口，只传这个窗口的声音。**Linux** 上即使投的是窗口，传的也是整台电脑的声音：别的程序在放的音乐也会传到电视上。

- **原因**：Wayland 下系统的共享对话框只把画面交给程序，不会说明这个窗口属于哪个程序，映湾桌面端没法知道该配哪一路声音。（Windows 能查出窗口属于哪个程序，所以能只取这个程序的声音。）
- **办法**：投屏时把别的声音停掉或静音，或者在设置里关掉**同时传声音**，让电视保持无声。

## 出问题时

- **列表里没有接收端**：两台设备在同一网络（不要用访客网络）；接收端已开启电脑投屏；防火墙允许专用网络。
- **需要有人在接收端确认**：接收端第一次会在它的屏幕上询问。
- **接收端正被另一台设备使用**：先停掉另一台，或在接收端允许接管。
- **接收端被重置过**：窗口提示密钥变化时，点**忘记这个接收端**并重新配对。
- **投得越久画面越差**（AMD 显卡）：0.1.5 已修复，请更新。
- **处在屏保里的电视一直黑屏**：电视上需要映湾 1.8.10，并开启**投屏时自动打开**（[怎么开](/zh/faq#电视停在屏保里投屏后一直黑屏怎么办)）。
- **日志**：“关于”里的**打开日志文件夹**。

## 隐私与安全

连接经过加密（TLS），双方用各自的密钥证明身份。配对后会记住接收端的密钥，密钥变化会被拒绝，直到你选择忘记它。没有账号。

你的屏幕内容只会发给你选的接收端，不会去别处。程序还会向本网站、GitHub 和一个中继询问最新版本。有两件事**不打开就不会发生**：每天一份匿名汇总（**使用统计**），以及程序意外结束或投屏出错时的报告（**错误报告**）。<a href="/zh/privacy">隐私政策</a>列出了每一个字段。

## 卸载

Windows：设置 → 应用 → CastBay Desktop → 卸载，会询问是否同时删除配对记录和日志；免安装版直接删文件夹（设置保存在 `%APPDATA%\com.weenas.castbay.desktop`）。Linux：`sudo apt remove castbay-desktop`。
