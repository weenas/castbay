- "关于 → 诊断信息 → 上传日志"可以发送问题报告（本机信息、最近的事件和应用日志，歌名、设备名称、网址和公网 IP 会先去掉），发送前会列出要发送的内容。发送后会显示报告编号和二维码，扫码打开反馈页面时会自动填好编号。
- 映湾意外退出后，主界面会询问是否发送这次问题的报告。想直接发送、不再询问，可以打开"自动发送错误报告"（设置 → 通用，默认关闭）。
- 匿名使用统计，默认关闭，需要你自己打开（设置 → 通用）：每天的投屏和出错次数、设备型号和 Android 版本，不包含任何名称、歌名或网址。关闭后会删除已发送的数据。每一项内容都列在隐私政策里。
- 有新版本时，"关于"页的"更新内容"会列出你当前版本之后的所有改动，可以先看再更新。
- 音乐界面上，手机名称过长时会滚动显示，不再盖住歌名；这一行也不再显示"已连接"。
- "关于"和设置页适配窄屏幕，例如竖着放的平板。
